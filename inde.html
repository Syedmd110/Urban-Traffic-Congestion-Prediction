Urban Traffic Congestion Prediction Platform

Project Introduction

This project predicts urban traffic congestion using historical traffic data and machine learning.

Project Objectives

  • Traffic data aggregation
  • Congestion prediction
  • Alternate route recommendation
  • Traffic analytics dashboard

Project Modules

  1. Authentication & Role Management
  2. Traffic Data Aggregation
  3. Congestion Prediction Engine
  4. Route Recommendation Service
  5. Analytics Dashboard

Technologies Used

Python, Flask, Machine Learning, HTML and CSS.
